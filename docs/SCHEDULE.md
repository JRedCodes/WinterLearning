# 🗓️ Suggested Schedule

Module estimates add up to **~290 hours** of focused work. Reading lessons slowly, stretch goals and getting stuck will realistically add 25–50%, and that's normal. **Nothing here is a deadline.** It's fine if this spills into the semester.

## ⚖️ Steady pace (~15–20 h/week)

Roughly one **phase every 2–3 weeks**, with the capstone spread over 3–4 weeks. That's about 4–5 months.

## 🎓 Semester pace (~6–10 h/week)

One module per week, and a checkpoint every phase. Prioritize this order if time is tight:

1. **Must-do for backend roles:** 05, 06, 07, 09, 11, 13, 15, 18, 20, 22, 23, 24, 26, 30
2. **Strongly recommended:** 12, 14, 16, 19, 25, 29, 31, 36
3. **Infra-flavored roles:** 32, 33, 34, 35
4. **Full-stack flavor:** R1, R2

## Daily rhythm that works

```
☕ 15 min   re-read yesterday's LOG.md entry + the lesson section you're on
🧠 2–3 h    deep work on the challenge (phone away, test:watch running)
🚶 break
🧠 2–3 h    finish / stretch goals / PR / review
🎤 20 min   answer 2–3 INTERVIEW.md questions out loud
📝 2 min    LOG.md entry
```

## Weekly ritual (Sunday, 30 min)

- `npm run progress` and look at the roadmap
- Re-read your LOG.md entries from the week: what kept confusing you? Re-read that lesson section.
- Pick one INTERVIEW.md from an *earlier* phase and answer it again from memory (spaced repetition)
- Plan next week's modules
